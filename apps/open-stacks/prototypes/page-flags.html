      About this prototype

      Page Flags is a back-of-book index across many books. Type a concept and see where it is discussed, page by page: in full texts we hold (lane 1) and in scanned books we can only search (lane 2), with each page marked by whether you can open it tonight.

      What is real

      • Lane 1 scans nine Project Gutenberg texts (public domain in the US; fetched 15 October 2026) live, in a Web Worker, for any term you type. Chapter ticks come from each text's own headings (CHAPTER, SECTION, PART, BOOK, "FIRST PAPER" and so on); contents pages and back-of-book indexes are hatched, so index entries are not mistaken for discussion. A "text page" is 2,400 characters of the Gutenberg file, not a printed page.
      • Lane 2 is a snapshot (October 2026) of Open Library's Search Inside API, which searches the Internet Archive's full-text index, including in-copyright lending scans. For each concept we kept the top 60 hits, English only, and joined them to Open Library works (LC call numbers, subjects) and to this site's catalog.
      • Flags at exact pages exist only for open scans: for those we ran each book's own search-inside endpoint and mapped every match to a BookReader page through the book's page manifest, which also gives printed page numbers. Links open that page with the phrase highlighted.
      • For lending and print-disabled scans the API says that a book matches and gives up to five short passages, but not where. (Its page_num field turned out to be the number of scanned pages in the volume, not the page of the hit; we checked it against archive.org metadata.) These books get one sealed slip instead of flags.
      • "False friends" (Dutch book-design annuals for Dutch book, Oliver Cromwell for Cromwell's rule) are folded away by a plain rule: the book's LC class or subjects must fit the concept's field. Books with neither stay visible.

      What is AI-generated

      • Synonym chips under the pens: precomputed by Claude, October 2026. Spot-check them; they only widen the full-text search.
      • Glosses on the example's pinned pages: precomputed by Claude, October 2026. Their quotations were checked verbatim against the page text by script.
      • When this page runs inside Claude, "Gloss this page" and "Ask Claude" call Claude live. Quotations in a live gloss are checked against the page and dropped if they are not verbatim; suggested concepts must exist in the list.

      Limits

      • Matching is literal: OCR noise, old spellings and hyphenation break some hits. Use synonym chips or a /regex/ in a pen.
      • Search Inside snippets are capped at about 150 characters: enough to locate a passage, not to read it.
      • HathiTrust full-text search would add page hits for millions more volumes, but it blocks scripted access, so it is not included.
      • Availability changes. The snapshot date is shown on the shelf.
