## What is LongtermWiki?

LongtermWiki is a monorepo framework for building LLM-assisted knowledge bases. It provides:

1. **Shared UI components** (`@cairn/ui`) - Graph visualizations, shadcn/ui components
2. **Shared Starlight components** (`@cairn/starlight`) - Footer and layout pieces shared across sites
3. **Site templates** - Astro + Starlight configurations

## Monorepo Structure

```
cairn/
├── apps/
│   ├── delegation-risk/         # Delegation Risk mini-textbook
│   ├── evaluation-engineering/  # Evaluation Engineering wiki
│   ├── reasoning-processes/     # Robust Reasoning Processes wiki
│   └── meta/                    # This documentation site
├── packages/
│   ├── config/       # @cairn/config - shared ESLint config
│   ├── starlight/    # @cairn/starlight - shared Starlight components
│   └── ui/           # @cairn/ui - shared components
├── starters/
│   └── research-wiki/  # degit-able template for new wikis
└── pnpm-workspace.yaml
```

## Quick Start

```bash
# Clone the repo
git clone https://github.com/quantified-uncertainty/cairn

# Install dependencies
pnpm install

# Run the meta docs
pnpm --filter meta dev
```
